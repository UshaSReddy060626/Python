# 🚀 10-Day Python Learning Journey

This repository documents my structured 10-day journey of learning Python from fundamentals to advanced concepts.  
Each day focuses on building strong core understanding through concepts + hands-on practice.

---

## 📅 Day 1 — Python Foundations
- Syntax and indentation
- Variables and data types
- Type casting (implicit & explicit)
- Operators (arithmetic, logical, comparison, bitwise, assignment, identity, membership)
- Input and output handling

---

## 📅 Day 2 — Strings, Lists & Tuples
- String operations and methods
- List operations and methods
- Tuple basics and immutability
- Slicing techniques
- Comprehensions
- Packing and unpacking

---

## 📅 Day 3 — Sets, Dictionaries, Conditionals & Loops
- Sets and set operations
- Dictionaries and key-value mapping
- Conditional statements (if, elif, else)
- Looping (for, while)
- Loop control (break, continue, pass)

---

## 📅 Day 4 — Functions & Modules
- Defining functions
- Arguments (*args, **kwargs)
- Scope (local vs global)
- Lambda functions
- Importing modules and creating reusable code

---

## 📅 Day 5 — Exception Handling & File I/O
- Try, except, finally blocks
- Handling runtime errors
- File handling (read, write, append)
- Working with CSV files
- Working with JSON data

---

## 📅 Day 6 — Object-Oriented Programming (OOP)
- Classes and objects
- Constructors (__init__)
- Inheritance
- Polymorphism
- Encapsulation
- Abstract classes
- Dunder methods

---

## 📅 Day 7 — Iterators, Generators & Decorators
- Iterators and __iter__, __next__
- Generators and yield
- Map, filter, reduce
- Decorator functions
- Functional programming basics

---

## 📅 Day 8 — Python Standard Library Deep Dive
- collections module
- re (regular expressions)
- datetime handling
- typing module
- logging system

---

## 📅 Day 9 — Concurrency, Async & Testing
- Threading basics
- Multiprocessing
- async / await
- Writing test cases using pytest
- Understanding parallel execution

---

## 📅 Day 10 — Problem Solving & Practice
- Logic building exercises
- Coding puzzles
- Mini problems combining all concepts
- Interview-style questions practice

---

## 🎯 Goal of This Journey
To build strong Python fundamentals and problem-solving ability that can support:
- Backend development
- AIML engineering fundamentals
- Internship/job readiness

---

## 🛠️ Tech Stack
- Python 3.x
- VS Code
- Git & GitHub

---

## 📌 Notes
This is a disciplined 10-day consistency challenge focused on learning + implementation, not just theory.

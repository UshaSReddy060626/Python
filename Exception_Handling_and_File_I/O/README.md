# 🚀 Exception Handling

Python exception handling allows programs to handle runtime errors gracefully instead of terminating unexpectedly. I practiced handling different types of exceptions, creating custom exceptions, and using exception handling techniques to make programs more reliable.

---

## 📚 Topics Covered

### ✅ Exception Handling

* `try`
* `except`
* Multiple `except` blocks
* `Exception as e`
* `finally`
* `raise` statement
* Custom exception classes

### ✅ Common Python Exceptions

* `ValueError`
* `ZeroDivisionError`
* `FileNotFoundError`
* `IndexError`
* `KeyError`

### ✅ File Handling Basics

* `open()`
* Read mode (`r`)
* Handling `FileNotFoundError` using `try` and `except`

* Defining Functions
* `return` Statement
* Default Arguments

* `from ... import`
* `if __name__ == "__main__"`

## 📝 What I Practiced

In this practice session, I explored how functions help organize and reuse code efficiently. I learned how to create functions, return values, and pass arguments using positional, default, keyword, variable-length (`*args`), and keyword variable-length (`**kwargs`) arguments.

I also practiced variable scope by understanding the difference between local and global variables, including how to modify global variables within a function using the `global` keyword.

Additionally, I learned how to write concise anonymous functions using `lambda`, import built-in Python modules using both `import` and `from ... import`, and understood the purpose of `if __name__ == "__main__"` for controlling code execution when a file is run directly or imported as a module.

## 🎯 Learning Outcome

This practice strengthened my understanding of Python functions, argument passing techniques, variable scope, lambda expressions, and module usage. These concepts are fundamental for writing clean, reusable, and modular Python programs and form an important foundation for advanced Python development.

# 🚀 Iterators, Generators, Decorators & Functional Programming

Today I explored some of Python's advanced features that make code more efficient, reusable, and expressive. I learned how iteration works internally, how generators create values lazily, how decorators extend functionality, and how functional programming tools like `map()`, `filter()`, and `reduce()` simplify data processing.

---

## 📚 Topics Covered

* `iter()` and `next()`
* `__iter__()` and `__next__()`
* Custom Iterator Class
* `yield` Keyword
* Generator Functions
* Generator Expressions
* Function Decorators
* Class Decorators
* `map()`
* `filter()`
* `reduce()` from `functools`

---

## 💻 Programs Practiced

* Iterating through a list using `iter()` and `next()`
* Creating a custom iterator class using `__iter__()` and `__next__()`
* Using the `yield` keyword to build generators
* Writing generator functions
* Creating generator expressions
* Implementing a function decorator
* Implementing a class decorator
* Doubling values using `map()`
* Filtering even numbers using `filter()`
* Summing values using `reduce()`
* Book Price Analyzer using `map()`, `filter()`, and `reduce()`

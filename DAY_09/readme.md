# 🚀 Day 09 – Asynchronous Programming, Concurrency & Testing in Python

Today I explored Python's asynchronous programming, concurrency, memory-efficient programming techniques, and testing frameworks. I learned how Python handles multiple tasks using asynchronous programming, threads, and processes, along with writing simple automated tests.

---

## 📚 Topics Covered

### 🔹 Asynchronous Programming (`asyncio`)

* `async` and `await` keywords
* `asyncio` Event Loop
* `asyncio.gather()` for running multiple asynchronous tasks

### 🔹 Threading

* `threading` module
* Creating threads using the `Thread` class
* Using the `target` parameter
* Global Interpreter Lock (GIL)

### 🔹 Multiprocessing

* `multiprocessing` module
* Creating processes using the `Process` class
* Using the `Pool` class for parallel execution

### 🔹 Memory-Efficient Programming

* Generator expressions
* Understanding generators and memory-efficient iteration

### 🔹 Python Comprehensions

* List comprehensions
* Comparison of traditional loops and comprehensions
* Writing cleaner and more efficient code

### 🔹 Testing in Python

* `unittest` module
* Writing basic test cases using `assertEqual()`
* Introduction to `pytest`
* Using the `assert` statement for testing
